# Separar el historial de la memoria explícita

Omnia podrá conservar localmente conversaciones para que el Propietario las consulte, pero no las incorporará automáticamente a sesiones futuras. Solo los Recuerdos y Compromisos solicitados explícitamente formarán la memoria activa, limitando la exposición de datos, el consumo de contexto y las inferencias no deseadas.
