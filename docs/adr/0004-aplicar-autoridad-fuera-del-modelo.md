# Aplicar la autoridad fuera del modelo

El harness de Omnia impondrá en código los límites de alcance, riesgo, tiempo, pasos y costo antes de ejecutar Acciones; estas reglas no dependerán de que el modelo las recuerde. Las autorizaciones podrán valer una vez o durante la Sesión actual y expirarán al cerrarla, mientras que borrar definitivamente, enviar, comprar, instalar o alterar la seguridad exigirá siempre una Confirmación específica y verificable.
