# Construir un núcleo modular con extensiones autorizadas

Omnia comenzará como una sola aplicación de Windows organizada en módulos profundos, y añadirá capacidades mediante paquetes declarativos que indiquen sus instrucciones, herramientas, permisos y verificaciones. Los dispositivos externos se incorporarán mediante adaptadores cuando aparezcan implementaciones reales; esto permite evolucionar hacia teléfonos y robots sin asumir desde el inicio el costo operativo de un sistema distribuido.
