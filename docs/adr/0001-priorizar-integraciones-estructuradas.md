# Priorizar integraciones estructuradas sobre automatización visual

Omnia realizará una Acción mediante una integración directa con el entorno cuando exista, utilizará después una interfaz estructurada y recurrirá a visión, teclado y ratón solamente como último recurso. Este orden favorece precisión, velocidad y verificabilidad, pero conserva la automatización visual para programas y dispositivos que no ofrecen otra forma de integración.
