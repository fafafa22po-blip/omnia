# Exigir ejecución acotada y verificable

Omnia ejecutará una sola Tarea activa, con límites de pasos, reintentos, tiempo y costo, y solo declarará éxito cuando obtenga Evidencia del resultado esperado. Las ambigüedades materiales, desviaciones del plan y nuevos riesgos detendrán la ejecución; esto sacrifica algo de fluidez para impedir ciclos, falsas finalizaciones y Acciones fuera del alcance autorizado.
