# Usar TypeScript y SQLite como base local

Omnia implementará su monolito modular con TypeScript sobre Node.js y conservará su estado local en SQLite, manteniendo la interfaz visual detrás de un seam hasta completar su diseño. Esta elección aprovecha el runtime disponible, facilita paquetes de capacidades y permite probar el harness sin interfaz, a cambio de encapsular cuidadosamente las integraciones nativas de Windows.
