# Mantener el harness independiente de modelos y proveedores

La conversación, memoria, autoridad, ejecución, verificación y medición pertenecerán a Omnia; los modelos de IA quedarán aislados detrás de un seam pequeño y contratos propios. OpenAI será el único adaptador inicial, y el Propietario decidirá posteriormente qué otros modelos incorporar; hasta que exista un segundo proveedor real no se construirá un enrutador multimodelo especulativo, y ningún cambio o fallback enviará datos sin autorización.
